# Motion and states

## Durations and easing

Two durations and one easing curve are defined: `--v-duration-fast` for immediate feedback and
`--v-duration-normal` for state changes, with `--v-easing-out` as the curve. Always take a duration
from these tokens instead of writing a time yourself: the reduced-motion overrides below only
reach animations that read the tokens.

<Canvas of={MotionStories.Durations} layout="padded" />

## Reduced motion

When the user asks their system to reduce motion (`prefers-reduced-motion: reduce`), the duration
tokens are redefined and every animation built on them follows. Nothing else has to be done in a
component.

## Interaction states

Hover is not a new color. `--v-state-hover` is a small share of the text color laid over whatever
surface the control sits on, so it works in light mode, dark mode, and under any accent. The
text on a hovered surface is tested at 4.5:1, and that includes the hover overlay.

Disabled controls fade as a whole with `--v-state-disabled-opacity`, and pressed controls shrink
slightly with `--v-state-press-scale`. WCAG exempts inactive controls from the contrast minimums
([1.4.3](https://www.w3.org/TR/WCAG22/#contrast-minimum)), but make sure a disabled control is
still recognizable as a control.
