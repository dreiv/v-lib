# VTextField

## Form example

A complete form using every `VTextField` variant: name, email with inline validation on
blur, password, search, tel, url, and a disabled field. The email field's error is
surfaced through the shared `VField` error slot, which uses `role="alert"` so assistive
technology announces it as soon as it appears.
