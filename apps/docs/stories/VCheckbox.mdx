# VCheckbox

## Indeterminate group

A parent "Select all" checkbox reflects the state of its children: checked when every
item is checked, unchecked when none are, and indeterminate when the selection is mixed.
Children can carry the same variations as a standalone checkbox — a description, or
`required`.
