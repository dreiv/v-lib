# v

A Vue 3 component library built to WCAG 2.2. The components are accessible by default: visible
focus, large click targets, text that stays readable in light mode, dark mode, forced colors, and
under the user's own accent color, and motion that stops when the user asks for less of it.

## Principles

- **Use what the system already provides.** Text is set in the user's system fonts. Page and text
  colors are the system `Canvas` and `CanvasText`, and the accent is the operating system accent.
  The library adapts to the person instead of asking them to adapt to it.
- **Name things by role.** Tokens say what a value is for, such as `--v-color-text-danger` or
  `--v-color-surface-raised`, never what it looks like.
- **Prove the contrast.** Color pairs are resolved and measured against WCAG 2.2 thresholds in the
  token tests, in light mode and in dark mode, with a spread of system accents.
- **Respect preferences.** Sizes are in `rem`, so they follow the browser font size. Durations are
  tokens, so reduced motion reaches every animation. The focus indicator follows forced-colors modes.
- **Target current browsers.** The latest Chrome, Edge, Firefox, and Safari. There are no
  fallbacks for older ones, which keeps the CSS small and modern.

## Getting started

Load the styles once, near the root of the app, then import components one at a time from their
own entry point.

```ts
import '@v/design-system/styles'
import { VButton } from '@v/design-system/button'
```

```vue
<template>
  <VButton variant="primary">Save</VButton>
</template>
```

The styles are organized in cascade layers, in this order: `v.reset`, `v.tokens`, `v.base`,
`v.components`, `v.utilities`. Your own unlayered CSS always wins over the library, so overriding a
component never needs a specificity fight.

Component pages show the variants and states of each component, with controls to try the props.

dark to check the live components. The token examples already show both schemes side by side.
