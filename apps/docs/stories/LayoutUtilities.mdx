# Layout Utilities

Plain CSS classes from `utilities.css` — not components. Compose them directly on
any element: a direction (`v-stack` or `v-inline`), an optional `v-wrap`, a `v-gap-*`
step, and `v-items-*` / `v-justify-*` for alignment.

## Wrapping groups

`v-inline` plus `v-wrap` for content that should flow onto new lines instead of
overflowing or shrinking — tag lists, filter chips, anything of unknown or variable count.

<Story of={LayoutUtilitiesStories.Wrap} />

## Gap scale

Every step of the space scale is exposed as a `v-gap-*` class. The examples below are generated
from `@v/design-tokens`, so a new space step shows up here the moment it exists. Add its class to
`utilities.css` at the same time.

<Story of={LayoutUtilitiesStories.GapScale} />

## Alignment

`v-items-*` sets the cross-axis (`align-items`); `v-justify-*` sets the main-axis
(`justify-content`). Neither is tied to a specific direction class — both work on
`v-stack` and `v-inline` alike.

## Composed example

A toolbar — `v-justify-between` plus `v-items-center` — is the case that motivated

## Container

`v-container` centers page content, caps it at `--v-container-inline`, and keeps a one-step
gutter on both sides.

<Story of={LayoutUtilitiesStories.Container} />

## Visually hidden

`v-visually-hidden` removes an element from view while leaving it available to screen readers.
Use it for text that gives a control its accessible name when the visible design is an icon.
